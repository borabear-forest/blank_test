01 T점수 · 표준화된 점수
1.
MMPI-2에서 사용하는 T점수 체계의 평균은 ( 50 )점이고, 표준편차는 ( 10 )점이다. 이처럼 평균과 표준편차가 미리 고정되어 있어 점수만 봐도 집단 내 위치를 즉시 파악할 수 있는 점수를 ( 표준화된 점수 )라고 한다.
① 50점  ② 10점  ③ 표준화된 점수(Standardized Score)
→ T점수는 평균·표준편차가 사전에 규정된 점수 체계. Z점수(평균 0, SD 1)와 함께 대표적 표준화 점수임.
2.
T점수에서 Z점수는 평균 ( 0 ), 표준편차 ( 1 )이며, 표준화된 점수 중 특별히 Z점수를 ( 표준 점수 )라고 부른다.
① 0  ② 1  ③ 표준 점수(Standard Score)
3.
다음 T점수를 표준편차 단위로 변환하여 빈칸을 채우시오. (T점수 평균=50, 표준편차=10)
T점수 평균 대비 해석
T = 60평균보다 1 표준편차 높음
T = 70평균보다 2 표준편차 높음
T = 65평균보다 1.5 표준편차 높음
T = 40평균보다 1 표준편차 낮음
T = 45평균보다 0.5 표준편차 낮음
공식: (T점수 − 50) ÷ 10 = 표준편차 단위
60→1SD↑ / 70→2SD↑ / 65→1.5SD↑ / 40→1SD↓ / 45→0.5SD↓
4.
MMPI-2에서 임상 범위의 기준 T점수는 ( 65 )점 이상이다. 이 기준은 ( 임의의 ) 가이드라인으로, 64점이 정상이고 65점부터 바로 문제가 있다는 의미가 아님을 유의해야 한다.
① 65점  ② 임의의(arbitrary)
→ 원판 MMPI는 70점 기준이었으나 MMPI-2부터 65점으로 낮춤.
5.
원점수(Raw Score)는 몇 문항에 체크됐는지를 단순 합산한 것으로, 이것만으로는 그 점수가 평균보다 ( 높은지 낮은지 )를 알 수 없다. 따라서 MMPI에서는 원점수를 ( T점수 )로 변환하여 사용한다.
① 높은지 낮은지(집단 내 상대적 위치)  ② T점수
→ 표준화된 점수를 쓰는 핵심 이유.
02 MMPI 개발 방식 — 경험적 준거방식
6.
MMPI의 대부분의 임상척도는 이론적 구성 개념이 아니라, ( 임상집단 )과 ( 정상(비교)집단 )의 문항별 응답 빈도 차이를 분석하여, 두 집단을 변별하는 데 유용한 문항들을 선정하는 ( 경험적 준거방식 ) (Empirical Criterion Keying)으로 개발되었다.
① 임상집단  ② 정상(비교)집단  ③ 경험적 준거방식
→ 이론적 논리보다 실제 집단 간 차이를 기준으로 문항 선정. MMPI의 핵심 개발 철학.
7.
타당도 척도 중 L 척도는 경험적 방식이 아닌 ( 논리적 ) 방식으로 제작되었으며, 일상적인 상황을 진술문으로 만들어 대부분의 사람이 인정하는 ( 사소한 인간적 약점 )을 부인하는 태도를 탐지한다.
① 논리적(rational) 방식  ② 사소한 인간적 약점(도덕적 결함)
→ "나는 가끔 화가 나면 짜증을 낼 때가 있다"를 '아니오'라고 답하는 식의 순진한 방어.
8.
F 척도 점수가 상승하는 이유 세 가지를 쓰시오. (기말 단골 — 교수님 직접 강조)
① 정신병리가 심함
② Faking bad (증상 과장)
③ 불성실한 응답
① 정신병리가 심한 경우 (우울·불안·강박 등)
② Faking bad — 자기 상태를 더 나쁘게 보이려는 의도적 왜곡
③ 불성실한 응답 — 무작위로 찍거나 대충 응답
→ F 척도: 정상인의 10% 미만이 응답한 60개 문항으로 구성.
03 K 교정 척도 — 개발 배경 · 의미 · 한계
9.
K 교정 척도는 심리적 문제가 있음에도 임상척도 점수가 ( 정상 범위 )인 환자 집단과, 실제 정상인 집단을 ( 경험적 ) 방식으로 비교하여 변별력 있는 문항들로 개발되었다. K 척도에서 점수가 높으면 기본적으로 ( 방어적 성향 )을 시사하며, 응답의 ( 신뢰성 )에 의문이 생긴다.
① 정상 범위  ② 경험적  ③ 방어적 성향  ④ 신뢰성
→ K교정도 경험적 준거방식으로 개발됨 — 시험 빈칸 포인트.
10.
K점수가 높다고 무조건 방어적으로 해석해서는 안 된다. K 척도는 기본적으로 수검자의 ( 자존감 ), ( 정서적 안정성 ), 문제 해결에 대한 ( 자원과 자신감 )을 반영하기도 하기 때문이다.
K점수가 50~60T일 때는 방어인지 실제 안정인지 판단이 어렵다.
① 자존감  ② 정서적 안정성  ③ 자원과 자신감(문제 해결 자원)
→ K점수 65T 이상: ~80% 방어적 / 70T 이상: ~99% 방어적 (교수님 기준).
11.
K 교정이 적용되는 임상 척도 5가지를 번호와 이름으로 쓰시오.
적용 척도척도 이름(영어 약어)K 교정 비율
( 1 )번 ( Hs, 건강염려증 ) +0.5K
( 4 )번 ( Pd, 반사회성 ) +0.4K
( 7 )번 ( Pt, 정신쇠약 ) +1.0K
( 8 )번 ( Sc, 조현병 ) +1.0K
( 9 )번 ( Ma, 경조증 ) +0.2K
1(Hs)+0.5K / 4(Pd)+0.4K / 7(Pt)+1.0K / 8(Sc)+1.0K / 9(Ma)+0.2K
→ 2·3·5·6·0번에는 K교정 미적용. 내용척도·보충척도·MMPI-A 전체 미적용.
12.
K 교정 계산 연습: K 원점수 = 16일 때,
1번 척도 원점수 15에 K교정을 적용한 값은?
15 + (0.5 × 16) = 15 + ( 8 ) = ( 23 )

4번 척도 원점수 24에 K교정을 적용한 값은?
24 + (0.4 × 16) = 24 + ( 6.4 ) → 반올림 = ( 30 )
1번: 15+8=23 / 4번: 24+6.4=30.4 → 30 (소수점 이하 버림)
→ 교수님 수업 예시 그대로. 계산 과정이 시험에 나올 수 있음.
13.
K 교정을 적용하지 않는 척도 유형 세 가지를 쓰시오.
① 내용 척도
② 보충 척도
③ MMPI-A 전체
① 내용 척도  ② 보충 척도  ③ MMPI-A 전체
→ 2·3·5·6·0번 임상척도도 미적용. MMPI-A에 미적용되는 것이 K교정 한계의 반증.
04 K 교정의 한계점 · 임상 적용
14.
K 교정의 한계점을 세 가지 서술하시오.
답:
① K가 높아도 실제로 자존감·안정성이 높은 사람이 있음 → 이들의 점수를 인위적으로 올리면 결과가 왜곡됨
② 방어적이면 내용척도·보충척도도 낮아질 텐데 거기엔 적용 안 함 → 논리적 일관성 부족
③ MMPI-A에도 적용 안 함 → K교정 논리의 근거가 약하다는 반증
(추가) K교정 비율의 정확한 근거 논문을 현재 찾기 어려움 (매우 오래된 자료)
15.
현장에서 MMPI 결과지를 볼 때, 대부분의 실무자들이 첫 페이지의 ( K교정된 ) 점수만 보는 경향이 있다. 그러나 교수님은 ( K교정 전(교정되지 않은) ) 점수도 반드시 함께 봐야 한다고 강조하였다. 이는 교정되지 않은 점수가 내담자를 더 ( 정확하게 ) 파악하는 데 유용한 경우가 많기 때문이다.
① K교정된  ② K교정 전(교정되지 않은)  ③ 정확하게
→ 결과지 두 번째 페이지에서 교정 전 점수 확인 가능.
16.
K 척도 점수가 평균(50T)에 가까운 사람은 K교정 전·후 T점수 차이가 ( 거의 없다 ). 반면 K 교정으로 인한 점수 변화가 가장 큰 척도는 교정 비율이 가장 높은 ( 7번(Pt) ) 척도이다.
① 거의 없다  ② 7번(Pt) — 1.0K로 전체 K점수를 더함
→ K점수가 극단적(매우 높거나 낮을)일 때 교정의 의미가 커짐.
05 통합 · 응용 서술형
17.
MMPI-2가 원점수 대신 T점수를 사용하는 이유를 두 가지 쓰시오.
① 원점수는 그 점수가 평균보다 높은지 낮은지, 얼마나 차이 나는지 알 수 없음
② T점수는 평균(50)과 표준편차(10)가 고정되어 점수만 봐도 집단 내 상대적 위치를 즉시 파악 가능
→ 이를 '표준화된 점수'라 하며, 임상가 간 소통과 해석에 일관성을 부여함.
18.
MMPI 임상척도 대부분이 '경험적 준거방식'으로 개발된 것과 달리, L 척도가 '논리적 방식'으로 개발된 이유를 설명하시오.
L 척도는 수검자가 얼마나 자신을 좋게 보이려 하는지를 측정하기 위해, 논리적으로 '누구나 인정할 수 있는 사소한 인간적 약점'을 담은 문항을 직접 구성함. 특정 임상집단과 비교할 필요 없이 문항 내용 자체로 방어를 탐지할 수 있기 때문.
19.
K 교정 척도 개발의 논리를 단계적으로 설명하시오.
① 심리적 문제가 있는데도 임상척도가 정상 범위인 환자 집단을 발견
② 이 환자 집단 vs 진짜 정상인 집단을 경험적으로 비교
③ 두 집단을 변별하는 문항들로 K 척도 구성
④ K가 높으면 방어적이라 판단 → 임상 점수가 낮게 나왔을 것 → K의 일정 비율을 더해 교정
⑤ 각 척도별 교정 비율(1=0.5K, 4=0.4K, 7·8=1.0K, 9=0.2K)은 연구로 경험적 결정
20.
보충 척도 중 점수가 높을 때 ( 긍정적 )으로 해석하는 3가지 척도를 쓰시오. 단, 이 척도들도 ( 방어적 )인 수검자에게서 점수가 올라갈 수 있으므로 맹목적으로 긍정 해석해서는 안 된다.
① Es (자아강도)
② Do (지배성)
③ Re (사회적 책임감)
① Es(Ego Strength, 자아강도)  ② Do(Dominance, 지배성)  ③ Re(Social Responsibility, 사회적 책임감)
→ MMPI에서 유일하게 점수 상승이 긍정적 의미를 가지는 보충 척도들.
단, 방어적 수검자도 이 척도들이 올라가므로 K·타당도 척도와 함께 판단해야 함.
06 MMPI-2 개정 배경 · 재표준화 · 역사
21.
MMPI 원판은 ( 1943 )년에 출판된 이후 한 차례도 개정 없이 사용되었다. 이로 인해 ( 규준 집단 )이 시대와 맞지 않게 되었고, 당시의 규준집단과 현재 평균적인 미국인이 매우 ( 다르다 )는 점이 개정의 핵심 이유 중 하나가 되었다.
① 1943년  ② 규준 집단  ③ 다르다
→ 규준 = 점수를 비교하기 위한 잣대·분포. 시대가 변하면 규준도 업데이트해야 함 (지능검사 플린 이펙트와 같은 논리).
22.
MMPI 원판 개정의 필요성으로 언급된 표현상의 문제 4가지를 쓰시오.
① 구식 표현
② 성차별적 표현
③ 특정 종교 편향
④ 대장·방광 기능 관련 문항
① 구식 표현 (군인 관련 등)  ② 성차별적 표현  ③ 특정 종교 편향 (예: "나는 주일에 교회를 간다")  ④ 대장·방광 기능 관련 문항
→ 또한 성적인 문항도 포함됨.
23.
원판 MMPI의 예비 문항의 폭이 좁아 충분히 반영하지 못한 내용 영역을 3가지 이상 쓰시오.
① 자살
② 약물 사용
③ 부부 관계
④ Type A 행동
⑤ 치료 관련 행동
① 자살  ② 약물 사용  ③ 부부 관계  ④ Type A 행동(경쟁적·성급한 성격 유형)  ⑤ 치료와 관련한 행동
→ Type A 성격: 성질이 급하고 경쟁적이며 참을성이 떨어지는 유형. 심혈관계 장애와 연관.
24.
MMPI-2 재표준화의 핵심 목표 4가지를 빈칸에 채우시오.
① 원판 MMPI와의 연속성 유지
② 폭넓고 대표성 있는 표준화 집단 구성
③ 문제 문항 수정·삭제
④ 새로운 척도 및 보강된 정보 제공
① 원판 MMPI와의 연속성 유지  ② 현 시점에 맞는 폭넓고 대표성 있는 표준화 집단 구성
③ 문제가 되는 문항의 수정·삭제  ④ 새로운 척도 및 보강된 정보 제공
25.
MMPI-2를 만들 때 원판 MMPI와의 '연속성'을 유지하는 것이 중요했던 이유를 설명하시오.
MMPI는 검사 자체보다 그것을 기반으로 축적된 연구가 매우 방대함.
MMPI-2로 개정하면서 골격과 형태가 달라지면, 기존 MMPI-1 연구 결과를 모두 활용할 수 없게 됨.
→ 연속성 유지 = MMPI-1의 누적 연구 자산을 MMPI-2에서도 끌어올 수 있도록 척도의 기본 구조를 동일하게 유지하는 것.
26.
MMPI-2 재표준화위원회는 ( 1982 )년에 결성되었으며, 시험용 검사지(AX)는 총 ( 704 )개 문항으로 구성되었다. 미국 ( 7 )개 지역에서 참여자를 모집하여 ( 2,900 )명을 조사한 후 불완전·의심스러운 자료를 제외하고 최종 ( 2,600 )명의 자료를 사용하였다.
① 1982년  ② 704문항 (기존 550문항 + 새로 제작 154문항)  ③ 7개 지역
④ 2,900명 조사 → 2,600명 최종 사용
→ 참여자 모집은 전화번호부를 통해 이루어짐.
27.
MMPI-2는 ( 1989 )년에 출판되었으며, 총 ( 567 )문항으로 구성되었다. 전반부 ( 370 )문항만으로도 전통적인 타당도 척도와 표준 임상척도 결과를 얻을 수 있다.
① 1989년  ② 567문항  ③ 370문항
→ 내담자가 370문항까지만 완료하고 중단해도 기본 척도 해석 가능.
28.
MMPI-2에서 임상 범위 기준이 원판의 ( 70 )점에서 ( 65 )점으로 낮아진 이유는, MMPI-2의 정상 집단이 원판보다 훨씬 더 ( 이질적 )이고 정상성의 ( 허들 )을 낮췄기 때문이다.
① 70점 → ② 65점  ③ 이질적  ④ 허들(기준)
→ 원판은 지나치게 '정상성이 강조된' 집단이 규준이었음. MMPI-2는 더 다양한 일반인 집단을 규준으로 삼아 기준선이 낮아짐.
29.
MMPI-A(청소년용)는 ( 1992 )년에 출판되었으며, 총 ( 478 )문항으로 구성된다. 청소년용이 별도로 개발된 이유는 청소년의 척도 상승 패턴이 ( 성인 )과 달라 별도의 ( 규준 )이 필요했기 때문이며, 성인용 시험 검사지는 ( AX ), 청소년용은 ( TX )로 불린다.
① 1992년  ② 478문항  ③ 성인  ④ 규준
⑤ 성인용=AX / 청소년용=TX
→ 전반부 350문항만으로도 주요 척도 산출 가능. 성인용과 동시에 자료 수집 진행됨.
30.
한국에서 MMPI가 처음 표준화된 연도는 ( 1963 )년이며, 한국판 MMPI-2/MMPI-A가 공식 발표된 연도는 ( 2005 )년이다. 국내 현장에서 MMPI-2 도입이 늦어진 주된 이유를 쓰시오.
① 1963년  ② 2005년
이유: 원판 MMPI는 라이센스 없이 무료로 사용되고 있었음(채점 프로그램도 기관마다 보유).
MMPI-2는 정식 라이센스 계약이 필요해 비용이 발생하게 되면서 현장에서 한동안 원판을 계속 사용함.
→ 1989년(미국 출판) → 2005년(한국판 발표) 16년의 간격.
