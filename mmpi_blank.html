범위 · "확률"이 아니라 "신뢰"로 표현. 확률로 보면 있다/없다 2가지뿐이라 항상 1/2이 됨
65.
단답형
95% 신뢰구간을 "확률적으로 반드시 존재한다"라고 해석하면 안 되는 이유를 쓰시오.
신뢰구간은 참점수의 범위를 추정하는 개념이지 확률 자체를 의미하는 것이 아니기 때문이다. 또한 확률로 보면 경우의 수가 있다/없다 2가지뿐이라 항상 1/2이 되어 95%라는 수치가 의미를 잃는다.
66.
단답형
GAI는 높고 CPI는 낮게 나타났을 때 어떻게 해석할 수 있는가?
일반 지적능력(언어이해·지각추론)은 양호하지만, 작업기억이나 처리속도에서 상대적 어려움이 있을 가능성을 시사한다. 인지 능력은 있으나 실행·처리 효율이 낮은 패턴.
67.
빈칸
WISC-IV에서 대체 소검사는 각 지표당 최대 1개, 전체 검사에서는 총 2개까지만 허용된다.
지표당 1개 / 전체 2개 · 대체 소검사를 남용하면 표준화 조건이 무너짐
68.
연결하기
① 통계적 유의성 ㄴ. 우연 가능성이 낮음
② 기저율 ㄱ. 일반집단에서의 흔함 정도
③ 대체 소검사 ㄷ. 제한적으로만 허용
ㄱ. 일반집단에서의 흔함 정도
ㄴ. 우연 가능성이 낮음
ㄷ. 제한적으로만 허용
통계적 유의성→ㄴ / 기저율→ㄱ / 대체 소검사→ㄷ
16 MMPI 해석 보충
69.
단답형
MMPI 해석 시 한 척도만으로 판단하면 안 되는 이유를 쓰시오.
MMPI는 전체 프로파일과 척도 간 관계를 함께 고려하여 해석해야 하기 때문이다. 단일 척도는 다차원적 속성을 가져 상승 원인이 다양하며, 코드타입 해석이 더 강력한 해석적 가설을 제공한다.
70.
모두 고르기
K척도 설명으로 옳은 것을 모두 고르시오.
① 방어성과 관련될 수 있다
② 자아강도와 관련될 수 있다
③ 무조건 병리적 의미를 가진다
④ 평균에서 지나치게 멀면 해석에 영향을 줄 수 있다
① ② ④ · K는 정상인에게서 자아강도·심리적 자원을 의미할 수 있음. 무조건 병리적이지 않음.
71.
빈칸
RC척도는 임상척도에 포함된 공통된 요인(의기소침·Demoralization) 영향을 줄이기 위해 개발되었다.
요인 (의기소침, Demoralization) · 공통 고통 요인 제거 후 개별 특성 강조
72.
단답형
RC척도가 개발된 이유를 쓰시오.
임상척도의 다차원성과 척도 간 문항 중복 문제, 공통요인(의기소침)의 영향을 줄이기 위해 개발되었다. 의기소침 요인을 제거한 씨앗척도를 만들어 RC 척도를 도출함으로써 변별력을 높였다.
17 FSIQ · GAI · CPI — 보강
73.
빈칸
FSIQ는 개인의 전체지능(전반적 지적능력)을 의미한다. GAI(일반능력지수)는 언어이해(VCI)와 지각추론(PRI)의 소검사 환산점수를 합산하여 산출한다. CPI(인지효율지수)는 작업기억(WMI)와 처리속도(PSI)의 소검사 환산점수를 합산하여 산출한다.
FSIQ = 전체지능 / GAI = VCI+PRI / CPI = WMI+PSI
74.
빈칸
GAI는 인지 효율보다 일반 지적능력 중심 능력을 더 반영하며, CPI는 작업기억과 처리속도를 반영하므로 인지처리 효율과 관련이 깊다.
GAI = 일반 지적능력 중심 / CPI = 인지 처리 효율
75.
연결하기
① FSIQ ㄴ. 전체지능
② GAI ㄷ. 언어이해 + 지각추론
③ CPI ㄱ. 작업기억 + 처리속도
ㄱ. 작업기억 + 처리속도
ㄴ. 전체지능
ㄷ. 언어이해 + 지각추론
FSIQ→ㄴ / GAI→ㄷ / CPI→ㄱ
76.
단답형
GAI와 CPI의 차이를 간단히 설명하시오.
GAI는 언어이해와 지각추론을 중심으로 한 일반 지적능력을 반영하며, CPI는 작업기억과 처리속도를 중심으로 한 인지 효율을 반영한다.
77.
단답형
FSIQ 대신 GAI를 참고할 수 있는 경우를 쓰시오.
지표 간 편차가 매우 크거나 작업기억·처리속도의 영향으로 전체 IQ 해석이 왜곡될 가능성이 있을 때 GAI를 함께 참고할 수 있다.
18 지표 간 차이비교 — 보강
78.
빈칸
두 지표 IQ 차이의 절대값이 임계치보다 크면 Y(유의한 차이 있음), 작거나 같으면 N(유의한 차이 없음)으로 표시한다. 차이값의 부호(±)는 어느 지표 점수가 더 큰지를 나타내며, 유의수준 값이 작을수록 판단 기준은 더 엄격해진다.
절대값 > 임계치 → Y / 절대값 ≤ 임계치 → N / 부호 = 어느 쪽이 큰지 / 유의수준↓ = 기준 엄격
79.
연결하기
① 절대값 > 임계치 ㄹ. 유의한 차이 있음
② 절대값 ≤ 임계치 ㄴ. 유의한 차이 없음
③ 마이너스(-) 부호 ㄱ. 뒤 지표 점수가 더 큼
④ 유의수준 감소 ㄷ. 판단 기준이 엄격해짐
ㄱ. 뒤 지표 점수가 더 큼
ㄴ. 유의한 차이 없음
ㄷ. 판단 기준이 엄격해짐
ㄹ. 유의한 차이 있음
①→ㄹ / ②→ㄴ / ③→ㄱ / ④→ㄷ
80.
단답형
지표 간 차이비교에서 임계치의 의미를 설명하시오.
임계치는 두 지표 점수 차이가 우연에 의해 발생한 것인지 판단하기 위한 기준값이다. 차이의 절대값이 임계치를 넘으면 유의한 차이로 본다.
19 점수 산출 흐름 — 보강
81.
빈칸
WISC-IV 점수 산출 흐름: 원점수 → 환산점수 → 지표점수(IQ) → FSIQ. 소검사 환산점수의 평균은 10, 표준편차는 3이며, IQ 점수의 평균은 100, 표준편차는 15이다.
원점수→환산점수→지표IQ→FSIQ / 환산점수: 평균10·SD3 / IQ: 평균100·SD15
82.
빈칸
원점수는 문항 응답을 단순 합산한 점수이므로 해석적 의미는 크지 않다. 실제 해석에서 중요한 것은 규준이 적용된 환산점수와 지표 IQ이다.
원점수 = 단순 합산, 의미 제한 / 환산점수·지표IQ가 실제 해석 기준
83.
연결하기
① 원점수 ㄷ. 단순 합산 점수
② 환산점수 ㄹ. 평균 10, SD 3
③ 지표 IQ ㄴ. 평균 100, SD 15
④ 백분위 ㄱ. 동일 연령 내 상대적 위치
ㄱ. 동일 연령 내 상대적 위치
ㄴ. 평균 100, SD 15
ㄷ. 단순 합산 점수
ㄹ. 평균 10, SD 3
①→ㄷ / ②→ㄹ / ③→ㄴ / ④→ㄱ
84.
단답형
원점수와 환산점수의 차이를 설명하시오.
원점수는 문항 점수를 단순 합산한 점수이며, 환산점수는 동일 연령 규준을 적용하여 변환한 점수이다. 환산점수는 평균 10, SD 3으로 개인 간 비교가 가능하다.
20 소검사와 지표 연결 — 보강
85.
빈칸
VCI는 언어이해 능력을 반영한다. PRI는 비언어적 추론과 시공간 능력을 반영한다. WMI는 정보를 일시적으로 저장하고 조작하는 작업기억 능력과 관련된다. PSI는 단순 시각 정보를 빠르고 정확하게 처리하는 처리속도 능력을 반영한다.
VCI=언어이해 / PRI=비언어적 추론·시공간 / WMI=작업기억 / PSI=처리속도
86.
연결하기
① 공통성 VCI
② 숫자 WMI
③ 토막짜기 PRI
④ 기호쓰기 PSI
⑤ 순차연결 WMI
⑥ 행렬추리 PRI
VCI · PRI · WMI · PSI
공통성→VCI / 숫자→WMI / 토막짜기→PRI / 기호쓰기→PSI / 순차연결→WMI / 행렬추리→PRI
87.
단답형
작업기억지표(WMI)가 낮게 나올 수 있는 사례를 설명하시오.
주의집중의 어려움이나 ADHD 특성을 가진 아동은 숫자외우기·순차연결 수행이 저하되어 WMI 점수가 낮게 나타날 수 있다.
88.
단답형
처리속도지표(PSI)의 특징을 설명하시오.
단순하거나 반복적인 시각 정보를 빠르고 정확하게 처리하는 능력을 반영하며, 속도와 주의집중의 영향을 받는다.
