02 T점수 · 표준화 · 규준
7.

MMPI-2 T점수의 평균 ( 50 )점, 표준편차 ( 10 )점. 평균·표준편차가 고정된 이런 점수를 ( 표준화된 점수 )라고 한다.
① 50 ② 10 ③ 표준화된 점수(Standardized Score)
8.
빈칸
Z점수는 평균 ( 0 ), 표준편차 ( 1 )이며, 특별히 Z점수를 ( 표준 점수 )라고 부른다.
0 / 1 / 표준 점수(Standard Score)
9.
빈칸
T점수를 표준편차 단위로 변환하시오. (평균=50, SD=10)
T점수해석
T = 60평균보다 1 SD 높음
T = 70평균보다 2 SD 높음
T = 65평균보다 1.5 SD 높음
T = 40평균보다 1 SD 낮음
공식: (T−50)÷10 / 60→1↑ / 70→2↑ / 65→1.5↑ / 40→1↓

65점 / 임의의(arbitrary) / 원판은 70점

03 MMPI-2 개발방식 — 경험적 준거방식
15.
빈칸
MMPI 임상척도 대부분은 ( 임상집단 )과 ( 정상집단 )의 응답 빈도 차이를 분석하는 ( 경험적 준거방식 )으로 개발되었다.
임상집단 / 정상집단 / 경험적 준거방식(Empirical Criterion Keying)
16.
빈칸
MMPI 임상척도는 경험적 방식으로 개발되었다. 경험적 방식은 정상집단과 환자집단을 변별하는 문항을 사용하며, 대표적 한계는 다차원성이다. MMPI 원판은 1943년, MMPI-2는 1989년에 개정되었다.
경험적 / 환자 / 다차원성 / 1943 / 1989
17.
빈칸
내용척도는 논리적 방식으로 개발되었으며 문항 간 내적 일관성이 높다. L 척도는 ( 논리적 ) 방식으로 제작되었으며, ( 사소한 인간적 약점 )을 부인하는 태도를 탐지한다.

코드타입 설명으로 옳은 것을 모두 고르시오.
① 가장 높은 척도 조합이다
② 65T 이상에서 해석한다
③ 정의된 코드타입은 5점 차이가 필요하다
④ 측정오차를 고려한다
⑤ 1점 차이도 중요하다
① ② ③ ④
44.
단답형
코드타입에서 5점 차이를 보는 이유는?
측정오차를 고려해 의미 있는 차이만 해석하기 위해서이다.
08 재구성 임상척도 (RC)
45.
빈칸
RC척도는 임상척도의 공통요인을 제거하였다. RC척도는 K교정을 적용하지 않는다. RC척도는 임상척도보다 내적 일관성이 높다.
공통 / K교정 미적용 / 내적
46.
모두 고르기
RC척도 특징으로 옳은 것을 모두 고르시오.
① 공통요인을 제거하였다
② K교정을 적용하지 않는다
③ 임상척도와 점수 차이가 발생할 수 있다
④ 개별요인의 영향이 중요하다
⑤ 임상척도와 항상 동일하다
① ② ③ ④
47.
OX
XRC척도는 K교정을 한다.
ORC척도는 공통요인을 제거하였다.
XRC와 임상척도는 항상 같은 패턴이다.
X / O / X
48.
단답형
RC척도와 임상척도 점수가 달라지는 이유는?
공통요인 제거와 K교정 제거 때문이며 개별요인 비중 차이의 영향도 받기 때문이다.
09 내용척도 · 내용소척도
49.
빈칸
내용척도는 논리적 방식으로 개발되었다. 내용척도는 문항 의미가 비교적 명확하다. 내용척도는 인상 관리에 취약하다.
논리적 / 명확 / 인상
50.
빈칸
내용소척도는 내용척도를 더 세부적으로 분류한 것이다. 내용소척도를 해석할 때는 일반적으로 모척도가 65T 이상일 때 고려한다.
분류(세분화) / 65T
