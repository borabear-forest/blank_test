01 T점수 · 표준화된 점수
1.
MMPI-2 T점수의 평균 ( 50 )점, 표준편차 ( 10 )점. 평균·표준편차가 고정된 이런 점수를 ( 표준화된 점수 )라고 한다.
① 50 ② 10 ③ 표준화된 점수(Standardized Score)
2.
Z점수는 평균 ( 0 ), 표준편차 ( 1 )이며, 특별히 Z점수를 ( 표준 점수 )라고 부른다.
① 0 ② 1 ③ 표준 점수(Standard Score)
3.
T점수를 표준편차 단위로 변환하시오. (평균=50, SD=10)
T점수해석
T = 60평균보다 1 SD 높음
T = 70평균보다 2 SD 높음
T = 65평균보다 1.5 SD 높음
T = 40평균보다 1 SD 낮음
공식: (T − 50) ÷ 10 / 60→1↑ / 70→2↑ / 65→1.5↑ / 40→1↓
4.
MMPI-2 임상 범위 기준 T점수는 ( 65 )점 이상. 이는 ( 임의의 ) 가이드라인이다.
① 65점 ② 임의의(arbitrary) / 원판은 70점 기준이었음.
5.
원점수만으로는 ( 높은지 낮은지 )를 알 수 없어 MMPI에서는 ( T점수 )로 변환하여 사용한다.
① 높은지 낮은지 ② T점수
02 MMPI 개발 방식 — 경험적 준거방식
6.
MMPI 임상척도 대부분은 ( 임상집단 )과 ( 정상집단 )의 응답 빈도 차이를 분석하는 ( 경험적 준거방식 )으로 개발되었다.
① 임상집단 ② 정상집단 ③ 경험적 준거방식(Empirical Criterion Keying)
7.
L 척도는 ( 논리적 ) 방식으로 제작되었으며, ( 사소한 인간적 약점 )을 부인하는 태도를 탐지한다.
① 논리적(rational) ② 사소한 인간적 약점
8.
F 척도 점수가 상승하는 이유 세 가지를 쓰시오.
① 정신병리가 심함
② Faking bad (증상 과장)
③ 불성실한 응답
① 정신병리 심함 ② Faking bad ③ 불성실 응답
03 K 교정 척도
9.
K 교정 척도는 심리적 문제가 있음에도 임상척도가 ( 정상 범위 )인 환자 집단과 정상인을 ( 경험적 ) 방식으로 비교하여 개발. K 높으면 ( 방어적 성향 ) 시사.
① 정상 범위 ② 경험적 ③ 방어적 성향
10.
K점수가 높아도 ( 자존감 ), ( 정서적 안정성 ), ( 자원과 자신감 )을 반영하기도 하므로 무조건 방어적으로 해석하면 안 된다.
① 자존감 ② 정서적 안정성 ③ 자원과 자신감
11.
K 교정이 적용되는 임상 척도 5가지를 쓰시오.
번호이름교정 비율
( 1 )번( Hs, 건강염려증 )+0.5K
( 4 )번( Pd, 반사회성 )+0.4K
( 7 )번( Pt, 정신쇠약 )+1.0K
( 8 )번( Sc, 조현병 )+1.0K
( 9 )번( Ma, 경조증 )+0.2K
1(Hs)+0.5K / 4(Pd)+0.4K / 7(Pt)+1.0K / 8(Sc)+1.0K / 9(Ma)+0.2K
12.
K 원점수=16일 때:
1번: 15 + (0.5×16) = 15 + 8 = 23
4번: 24 + (0.4×16) = 24 + 6.4 → 반올림 = 30
1번: 23 / 4번: 30
13.
K 교정 미적용 척도 유형 세 가지를 쓰시오.
① 내용 척도
② 보충 척도
③ MMPI-A 전체
① 내용 척도 ② 보충 척도 ③ MMPI-A 전체
04 K 교정의 한계 · 임상 적용
14.
K 교정의 한계점을 세 가지 서술하시오.
① K 높아도 실제 안정성 높은 사람 있어 왜곡 가능
② 내용·보충 척도엔 미적용 → 논리적 일관성 부족
③ MMPI-A에 미적용 → 근거 약하다는 반증
15.
실무자들은 주로 ( K교정된 ) 점수만 보지만, 교수님은 ( K교정 전(교정되지 않은) ) 점수도 함께 봐야 한다고 강조하였다.
① K교정된 ② K교정 전(교정되지 않은)
16.
K 교정으로 인한 점수 변화가 가장 큰 척도는 ( 7번(Pt) )이다.
7번(Pt) — 1.0K 전체 적용
05 통합 서술형
17.
MMPI-2가 T점수를 사용하는 이유 두 가지를 쓰시오.
① 원점수는 집단 내 상대적 위치 파악 불가
② T점수는 평균(50)·SD(10) 고정으로 즉시 위치 파악 가능
18.
L 척도가 논리적 방식으로 개발된 이유를 쓰시오.
사소한 인간적 약점을 담은 문항 내용 자체로 방어를 탐지할 수 있어 임상집단 비교가 불필요.
19.
K 교정 척도 개발 논리를 단계적으로 쓰시오.
① 문제 있어도 임상척도 정상인 환자 집단 발견 → ② vs 정상인 경험적 비교 → ③ 변별 문항으로 K 구성 → ④ K 높으면 방어적 판단 → 일정 비율 더해 교정
20.
점수 상승이 ( 긍정적 )으로 해석되는 보충 척도 3가지를 쓰시오.
① Es (자아강도)
② Do (지배성)
③ Re (사회적 책임감)
Es(자아강도) / Do(지배성) / Re(사회적 책임감)
